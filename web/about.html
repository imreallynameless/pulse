Pulse

A small, open-source widget that displays the latest heart-rate measurement and how long ago it was measured.

This deployment is operated by Lei Wu for personal use. Google Health supplies the account owner's synced heart-rate data. The widget shares only the latest BPM and measurement time publicly; it is not a live medical monitor.

Connecting a Google account requires the private owner key. This deployment does not offer public account registration.
